# My Personal Webpage

A sleek, responsive personal portfolio webpage built with **HTML5** and **CSS3**, featuring a custom animated falling-zeros background effect and a clean dark theme. 

## Features

- **Custom CSS Animation:** Implements a dynamic "matrix-style" falling zeros background animation using pure CSS keyframes.
- **Dark Theme Aesthetic:** Styled with a deep navy blue background and minimalist layout.
- **Personal Introduction:** Shares my background as a Software Engineering student and my early programming journey.
- **Curated Favorites:** Showcases some of my favorite books and go-to educational coding resources.
- **Responsive Layout:** Flexbox-powered structure ensuring clean alignment across screen sizes.



## Built With

- **HTML5** — Semantic document structure
- **CSS3** — Custom styling, Flexbox layout, and `@keyframes` animations
